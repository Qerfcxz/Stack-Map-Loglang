The data structure consists of seven stacks, five mappings, and one counter.

The seven stacks from top to bottom are (with the right end as the top of stack):
1. Input Stack: IP
2. Variable Upper Stack: VU
3. Variable Middle Stack: VM
4. Variable Lower Stack: VL
5. Output Stack: OP
6. Modifier Stack: MD
7. Relation Stack: RL

Among these, the Variable Upper Stack (VU) is pre-populated with an infinite stream of distinct variables; the Relation Stack (RL) is pre-populated with a single "Deter" token; and the Counter (Count) is initialized to 0.

The five mappings are:
1. Environment Map: Emap
2. Quantifier Map: Qmap
3. Set Map: Smap
4. Formula / Filter Map: Fmap
5. Associated Variable Map: Amap

All keys in these mappings are variable names.

Notational Conventions:
- Lowercase letters denote variables.
- Uppercase letters denote arbitrary elements / expressions.
- "A:S" denotes that A is a Set token.
- "A:R" denotes that A is a Relation token.
- "A:Q" denotes that A is a Quantifier token.
- "A:C" denotes that A is a Connective token.
- "Ω(a)" denotes that a is an Event variable.
- "#" denotes a null/empty expression (# ∧ A = A, A ∧ # = A).
- "-" denotes an empty stack.
- "+ A" denotes that the top element of the stack is A, with "+" representing the rest of the stack.
- "[..., A]" denotes a List whose top/tail element is A.

Operational Conventions:
- build A a b B C D := A a ∈ {b ∈ B | C} D.
  Example: build ∃ n z Z (z >= 0) (n * n = n) := ∃n ∈ {z ∈ Z | z >= 0} (n * n = n)
- Lookup failures:
  - Emap: raises an error
  - Qmap: defaults to ∃
  - Smap: raises an error
  - Fmap: raises an error
  - Amap: raises an error

Execution Pipeline:
1. Receive input.
2. Match against Initial Rules once (top-to-bottom).
3. Loop-match against Loop Rules until no further rule matches (top-to-bottom).
4. Return to Step 2.

AdjectiveMacro := [Combine, Modify, New, λx.λy.λz.[Event, Build, Build, Predicate:R, Object:R, Use, Subject:R, x, #, True, Use, Get, AdjectiveCorrespondingPredicate:S, Stop, Formula, y, z, AdjectiveCorrespondingSet:S, Stop, Bubble, y]]
