This data structure consists of eight stacks, five mappings, and one counter.

The eight stacks from top to bottom are as follows (all with the right end as the top of the stack):
1. Input Stack (IP)
2. Variable Stack (VR)
3. Component Stack (CM)
4. Quantification Stack (QN)
5. Modifier Stack (MD)
6. Relation Stack (RL)
7. Clause Stack (CL)
8. Output Stack (OP)
Among them, the Variable Stack is pre-populated with infinitely many mutually distinct variables, the Quantification Stack is pre-populated with one "None", the Modifier Stack is pre-populated with one "Stop", the Relation Stack is pre-populated with one "Deter", and the counter is initialized to 0.

The five mappings are:
1. Environment Map (Emap)
2. Quantifier Map (Qmap)
3. Set Map (Smap)
4. Formula Map (Fmap)
5. Associated Variable Map (Amap)
All mapping keys are variable names.

Symbol Conventions:
Lowercase letters represent variables.
Uppercase letters represent arbitrary elements.
"A:S" denotes that A is a set word.
"A:R" denotes that A is a relation word.
"A:Q" denotes that A is a quantifier word.
"A:C" denotes that A is a connective word.
"A:F" denotes that A is a transform word.
"Ω" denotes the event set.
"#" denotes the empty formula (# ∧ A = A, A ∧ # = A).
"IP/VR/CM/QN/MD/RL/CL/OP: A" indicates that the top element of the corresponding stack is A, regardless of the remaining elements.
"[...,A]" indicates that the head element of the List is A.

Operational Conventions:
build A a b B C D := A a∈{b∈B|C} D. For example: build ∃ n z Z (z>=0) (n*n=n) := ∃n∈{z∈Z|z>=0}(n*n=n)
Emap lookup failure throws an error; Qmap lookup failure returns ∃ (Exist); Smap lookup failure throws an error; Fmap lookup failure throws an error; Amap lookup failure throws an error.

Execution Flow:
1. Input
2. Match Start Rules once (matched from top to bottom)
3. Repeatedly match Loop Rules in a loop until no rule matches (matched from top to bottom)
4. Execute step 2 again

<Macro Definitions>

(N-ary nominalization closing macros are defined analogously)

Binary Clause Closing Macro := [Clause, Build, Build, (i2,i1)]
(N-ary clause closing macros are defined analogously)

Binary Predicate Macro := [Deter, Predicate:R, Object:R, Absorb, Subject:R, Absorb, Absorb, Get, Join, [Use], Predicate_Name:S]
(N-ary predicate macros are defined analogously)

Noun Macro := [Deter, Join, [Use], Noun:S]

Relation Macro := [Add, Join, [Relation:R]]

Adjective Macro := [Combine, Modify, New, λx.λy.λz.[Event, Build, Build, Predicate:R, Object:R, Use, Subject:R, x, #, True, Use, Get, Adjective_Predicate:S, Empty, Formula, y, z, Adjective_Set:S, Empty, Bubble, y]]

Adverb Macro := [For, Modify, New, λx.λy.λz.[Event, Build, Build, Predicate:R, Object:R, Use, Subject:R, x, #, True, Use, Get, Adverb_Predicate:S, Empty, Formula, y, z, Adverb_Set:S, Empty, Bubble, y]]
