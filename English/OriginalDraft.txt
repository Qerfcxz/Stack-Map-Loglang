This data structure consists of five stacks and five mappings.

The five stacks from top to bottom are as follows (all with the right end as the top of the stack):
1. Input stack
2. Variable upper stack
3. Variable middle stack
4. Variable lower stack
5. Output stack
Among them, the variable upper stack is pre-populated with infinitely many mutually distinct variables.

The five mappings are:
1. Environment mapping Emap
2. Quantifier mapping Qmap
3. Set mapping Smap
4. Expression mapping Fmap
5. Associated variable mapping Amap
All mappings have variable names as their keys and values.

Notational Conventions:
Lowercase letters denote variables
Uppercase letters denote arbitrary elements
"A:S" indicates that A is a set word
"A:R" indicates that A is a relation word
"A:Q" indicates that A is a quantifier word
"A:C" indicates that A is a connective word
"#" denotes the empty expression (#∧A=A, A∧#=A)
"|" denotes an empty stack
"|| A" denotes that the top element of the stack is A, and the remaining stack elements are collectively denoted by "||"
"[...,A]" denotes that the top element of the List is A

Operational Conventions:
build A a b B C D := A a∈{b∈B|C} D. For example: build ∃ n z Z (z>=0) (n*n=n) := ∃n∈{z∈Z|z>=0}(n*n=n)
If the corresponding mapping does not exist in Emap, lookup returns empty; if not in Qmap, lookup returns ∃; if not in Smap, lookup returns the universal set; if not in Fmap, lookup returns #; if not in Amap, lookup throws an error.

Execution Flow:
1. Input
2. Match a start rule once (top-down matching)
3. Repeatedly match loop rules in a loop until no rule matches (top-down matching)
4. Execute Step 2 again

<Macro Definitions>

Binary Predicate Macro := [Predicate:R, Object:R, Use, Subject:R, Use, Use, Get, Predicate_Set:S]

(Analogous for multi-place predicates)

Adjective Macro := [Modify, λx.λy.λz.Adjective]
(If the adjective is "heavy", then "λx.λy.λz.heavy" represents "∃a∈{y∈A|z} such that the weight of x is a", where A is the set of relatively large weights)

Adverb Macro := [Polish, λx.λy.λz.Adverb]
(Analogous to adjective macros)

Empty Adverb Macro := [z, #]
(Used to separate adverbs and prevent them from interacting with each other)
