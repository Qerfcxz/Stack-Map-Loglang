This data structure consists of six stacks and five maps.

The six stacks from top to bottom are as follows (in all stacks, the rightmost end represents the top of the stack):
1. Input Stack (IP)
2. Variable Upper Stack (VU)
3. Variable Middle Stack (VM)
4. Variable Lower Stack (VL)
5. Output Stack (OP)
6. Modifier Stack (MD)
Among them, the Variable Upper Stack is pre-populated with infinitely many mutually distinct variables.

The five maps are:
1. Environment Map (Emap)
2. Quantifier Map (Qmap)
3. Set Map (Smap)
4. Formula Map (Fmap)
5. Association Map (Amap)
All map keys are variable names.

Notational Conventions:
Lowercase letters denote variables.
Uppercase letters denote arbitrary elements / expressions.
"A:S" indicates that A is a set word.
"A:R" indicates that A is a relational word.
"A:Q" indicates that A is a quantifier word.
"A:C" indicates that A is a connective word.
"Ω(a)" indicates that a is an event variable.
"#" denotes an empty expression / dummy (# ∧ A = A, A ∧ # = A).
"-" denotes an empty stack.
"+ A" indicates that the top element of the stack is A, with the rest of the stack denoted by "+".
"[...,A]" indicates that the top (last) element of the List is A.

Operational Conventions:
build A a b B C D := A a∈{b∈B|C} D. For example: build ∃ n z Z (z>=0) (n*n=n) := ∃n∈{z∈Z|z>=0}(n*n=n)
Lookup failure behavior: Emap lookup failure raises an error; Qmap lookup failure returns ∃; Smap lookup failure raises an error; Fmap lookup failure raises an error; Amap lookup failure raises an error.

Execution Flow:
1. Input
2. Match a Start Rule once (matched from top to bottom)
3. Repeatedly match Loop Rules until no rule can match (matched from top to bottom)
4. Return to step 2

<Macro Definitions>

Binary Predicate Macro := [Predicate:R, Object:R, Use, Subject:R, Use, Use, Get, Predicate_Set:S]
(Multi-ary predicates follow the same principle)

Adjective Macro := [Combine, Modify, New, λx.λy.λz.[Event, Build, Build, Predicate:R, Object:R, Use, Subject:R, x, #, True, Use, Get, Adjective_Predicate:S, Stop, Formula, y, z, Adjective_Set:S, Stop, Bubble, y]]

Adverb Macro := [For, Modify, New, λx.λy.λz.[Event, Build, Build, Predicate:R, Object:R, Use, Subject:R, x, #, True, Use, Get, Adverb_Predicate:S, Stop, Formula, y, z, Adverb_Set:S, Stop, Bubble, y]]

Permutation Concluding Macro := [End, Permutation_Word]
