This data structure consists of seven stacks, five mappings, and one counter.

The seven stacks from top to bottom are (all with the right end as the top):
1. Input Stack (IP)
2. Var Upper Stack (VU)
3. Var Middle Stack (VM)
4. Var Lower Stack (VL)
5. Output Stack (OP)
6. Modifier Stack (MD)
7. Relation Stack (RL)
The Var Upper Stack is pre-populated with infinitely many mutually distinct variables, the Relation Stack is pre-populated with one Deter, and the counter is initially set to 0.

The five mappings are:
1. Environment Map (Emap)
2. Quantifier Map (Qmap)
3. Set Map (Smap)
4. Formula Map (Fmap)
5. Association Map (Amap)
The keys of all mappings are variable names.

Notational Conventions:
Lowercase letters denote variables.
Uppercase letters denote arbitrary elements.
"A:S" denotes that A is a set word.
"A:R" denotes that A is a relation word.
"A:Q" denotes that A is a quantifier word.
"A:C" denotes that A is a connective word.
"Ω(a)" denotes that a is an event variable.
"#" denotes an empty expression (#∧A=A, A∧#=A).
"-" denotes an empty stack.
"+ A" denotes that the top element of the stack is A, with the remaining stack elements represented collectively by "+".
"[...,A]" denotes that the top element of the List is A.

Operational Conventions:
build A a b B C D := A a∈{b∈B|C} D. For example: build ∃ n z Z (z>=0) (n*n=n) := ∃n∈{z∈Z|z>=0}(n*n=n)
Emap lookup failure throws an error; Qmap lookup failure returns ∃; Smap lookup failure throws an error; Fmap lookup failure throws an error; Amap lookup failure throws an error.

Execution Flow:
1. Input
2. Match a start rule once (top-down matching)
3. Repeatedly match loop rules until no rule can match (top-down matching)
4. Execute Step 2 again

<Macro Definitions>

Binary_Predicate_Macro:=[Deter,Predicate:R,Object:R,Absorb,Subject:R,Absorb,Absorb,Get,Join,[Use],Predicate_Set:S]
(Similarly for n-ary predicates)

Noun_Macro:=[Deter,Join,[Use],Noun:S]

Relation_Macro:=[Add,Join,[Relation:R]]

Adjective_Macro:=[Combine,Modify,New,λx.λy.λz.[Event,Build,Build,Predicate:R,Object:R,Use,Subject:R,x,#,True,Use,Get,Adj_Predicate:S,Stop,Formula,y,z,Adj_Set:S,Stop,Bubble,y]]

Adverb_Macro:=[For,Modify,New,λx.λy.λz.[Event,Build,Build,Predicate:R,Object:R,Use,Subject:R,x,#,True,Use,Get,Adv_Predicate:S,Stop,Formula,y,z,Adv_Set:S,Stop,Bubble,y]]

Adverb_Combine_Macro:=[For,Combine,Cancel]

Adverb_Combine_Cancel_Macro:=[Combine,Cancel]

Adverb_Exchange_Macro:=[For,Exchange]

Permutation_Closing_Word:=[End,Permutation_Word]
