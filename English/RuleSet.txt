This data structure consists of six stacks, one number stream, one scalar register, and eight maps.

The six stacks and one number stream are, from top to bottom (with the right end as the top of stack in all cases):
1. Input Stack (IP): Queue of instruction blocks, token streams, and unpacked macros awaiting execution.
2. Number Stream (NM): Pre-initialized infinite stream of monotonically increasing natural numbers: 1 2 3 ...
3. Quantifier Queue / Stack (QN): Argument entity queue awaiting quantifier closure.
4. Wait Stack (WT): Staging area for higher-order continuation closures, intermediate entities, and modifier polarities.
5. Component Stack (CM): Storage for active components and their truth-polarity cursors, formatted as Polarity Entity.
6. Permutation Stack (PR): Buffer and pipeline for permutation group operations.
7. Output Stack (OP): Immediate evaluation, computation, and reduction workbench.

One scalar register:
- Focus Register (<F>): Scalar integer, initialized to 0, tracking the core host entity currently undergoing closure.

The eight maps are:
1. Restrictor Map (Imap): Accumulates nominal intensional restriction formulas.
2. Nuclear Scope Map (Omap): Accumulates external main assertive predicate propositions.
3. Quantifier Map (Qmap): Maps entity variables to generalized quantifier forces (default: Exist).
4. Base Set Map (Smap): Records the base category name of an entity.
5. Mode Map (Mmap): True = Inner mode / writes to Imap; False = Outer mode / writes to Omap.
6. Focus Flag Map (Fmap): True = Protected host entity of an active relative clause; False = Ordinary argument.
7. Environment Map (Emap): Dynamic variable alias map for cross-clause pronoun coreference.
8. Global Lexical Macro Map (Map): Global dictionary mapping set name strings to their corresponding predicate frame macro code.

All keys of entity-related maps are entity numerical IDs.

Notational Conventions:
- Lowercase letters denote variables or arbitrary elements.
- Uppercase letters denote arbitrary elements or specific types.
- "A:N" denotes an entity numerical ID.
- "A:S" denotes a set word.
- "A:R" denotes a relation word.
- "A:QQ" denotes a quantifier word.
- "A:SS" denotes a transform word.
- "A:B" denotes a boolean value (True or False).
- "Ω" denotes the event universe / event set.
- "#" denotes the empty/dummy expression (# ∧ A = A, A ∧ # = A, # ∧ # = #).
- "!" denotes the execution trigger symbol.
- "[..., A]" denotes a list whose top (right-end) element is A.
- "??" denotes any matched stack or map.
- "∇" denotes side-effect operations during state transition.
- "-" denotes nothing (remains unchanged / no-op / identity).
Stacks and maps not explicitly mentioned in a rule remain unchanged by default.

Execution Workflow:
1. Push input instruction sequence into IP.
2. Match start rules once (from top to bottom).
3. Iteratively match loop rules until reaching a fixed point (from top to bottom).
4. Repeat from step 2 until IP is empty.
